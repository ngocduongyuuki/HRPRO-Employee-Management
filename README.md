## English

### 📌 Introduction

HRPRO is a web-based Human Resource Management System designed to support employee administration and streamline common HR operations.

The application provides an interactive interface for managing employee information, organizing departments, tracking attendance, handling leave requests, and managing payroll-related information.

This project was developed to demonstrate web application development, data management, and interactive user interface design.

### ✨ Key Features

- **Employee Management:** Add, edit, delete, and view employee profiles.
- **Department Management:** Organize employees by department and manage department information.
- **Employee Search & Filtering:** Search, filter, and sort employee records.
- **Pagination:** Navigate through employee lists more conveniently.
- **Attendance Management:** Track employee attendance information.
- **Leave Management:** Manage employee leave requests and their statuses.
- **Payroll Management:** View and manage salary information, tax calculations, and salary adjustments.
- **Statistics:** Display employee-related statistics.
- **Excel Import & Export:** Import employee data from Excel files and export data for reporting.

### 🛠️ Technologies Used

- HTML5
- CSS3
- JavaScript
- React
- SheetJS (XLSX)

### 🚀 Getting Started

1. Clone this repository:

   ```bash
   git clone https://github.com/YOUR-USERNAME/HRPRO-Employee-Management.git
   ```

2. Open the project folder.
3. Open `index.html` in a modern web browser.
4. Make sure you have an internet connection if the application loads external libraries or resources.

## Tiếng Việt

### 📌 Giới thiệu

HRPRO là hệ thống quản lý nhân sự được xây dựng dưới dạng ứng dụng web, nhằm hỗ trợ công tác quản lý thông tin nhân viên và tối ưu hóa các nghiệp vụ nhân sự cơ bản.

Ứng dụng cung cấp giao diện tương tác cho phép quản lý hồ sơ nhân viên, tổ chức phòng ban, theo dõi chấm công, xử lý đơn nghỉ phép và quản lý các thông tin liên quan đến tiền lương.

Dự án được thực hiện nhằm thể hiện khả năng xây dựng ứng dụng web, quản lý dữ liệu và thiết kế giao diện tương tác.

### ✨ Các chức năng chính

- **Quản lý nhân viên:** Thêm, chỉnh sửa, xóa và xem thông tin hồ sơ nhân viên.
- **Quản lý phòng ban:** Phân loại nhân viên theo phòng ban và quản lý thông tin từng phòng ban.
- **Tìm kiếm và lọc nhân viên:** Hỗ trợ tìm kiếm, lọc và sắp xếp danh sách nhân viên.
- **Phân trang:** Giúp việc xem và quản lý danh sách nhân viên thuận tiện hơn.
- **Quản lý chấm công:** Theo dõi thông tin chấm công của nhân viên.
- **Quản lý nghỉ phép:** Tiếp nhận và quản lý các yêu cầu nghỉ phép cùng trạng thái xử lý.
- **Quản lý tiền lương:** Theo dõi thông tin lương, tính toán thuế và điều chỉnh lương.
- **Thống kê:** Hiển thị các số liệu thống kê liên quan đến nhân sự.
- **Nhập và xuất Excel:** Hỗ trợ nhập dữ liệu nhân viên từ Excel và xuất dữ liệu phục vụ báo cáo.
